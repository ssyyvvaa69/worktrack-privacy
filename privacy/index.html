WorkTrack Privacy Policy

Last updated: October 12, 2026

Developer: Miia Forge
Privacy contact: miiaforge.dev@gmail.com

1. General information

This policy describes WorkTrack 1.0, an Android application for personal tracking of working time, earnings, vacation, holidays, statistics and notes. WorkTrack does not require a WorkTrack account and primarily stores user data locally on the device.

Optional Google Drive backup, official holiday requests, Android system backup and user-initiated file transfers are explained below.

2. Data used by WorkTrack

WorkTrack uses work dates and hours, hourly rates, segments and multipliers, vacation entries, goals, notes and custom holidays entered by the user. It calculates earnings and statistics from these records.

The application also uses settings including language, interface preferences, currency, holiday calendar and user-selected background images. These data support application functions and are not used for advertising profiling.

WorkTrack does not request GPS or location permissions. Region-related choices use the system locale and application settings, not GPS location.

3. Local storage and Android system backup

Work records, goals and custom holidays are stored in an internal application database. Settings and processed background images are stored in application storage.

WorkTrack does not send work records, rates, earnings, notes, custom holidays or photographs to a Miia Forge server.

Local data remains until deleted by the user, replaced during restoration, or removed by clearing application data.

Android system backup is enabled (android:allowBackup=true). Depending on the device, Google account and Android settings, the operating system may automatically back up or transfer eligible application data. This is an Android system function and is separate from WorkTrack's optional Google Drive backup.

4. Google Drive backup

Google Drive backup is optional. When the user enables or uses this feature, WorkTrack uses Google authentication and the Google Drive API.

WorkTrack requests the Google Drive application-data permission:

https://www.googleapis.com/auth/drive.appdata

This permission allows WorkTrack to create and manage its own backup files inside Google Drive's hidden application data area (appDataFolder).

It does not give WorkTrack access to the user's ordinary Google Drive files, documents or folders.

Depending on the backup settings selected by the user, WorkTrack may create, list, restore and delete WorkTrack backup files in this application-specific storage area.

Backup archives may contain application data and settings required to restore WorkTrack, including work records, notes, custom holidays, goals and other supported application data.

These backup files are transferred directly between WorkTrack and the user's Google Drive account through Google services. Miia Forge does not receive or store a separate server copy of these backups.

Google processes authentication and Google Drive requests according to Google's own privacy policies and terms.

Disabling Google Drive backup stops future backup operations initiated by WorkTrack. Existing backups may remain in the application's Google Drive data area until they are deleted using the application's backup controls, applicable Google account controls, or otherwise removed by Google according to its policies.

5. Manual export, sharing and restoration

The user may initiate local backups, exports and sharing. Backups may contain work records, notes, custom holidays, goals, settings and other supported application data.

CSV and XLSX exports contain records and calculated information for the selected scope, including notes where applicable.

Android's document picker, CreateDocument interface and Sharesheet allow the user to choose a storage destination or receiving application. The selected destination may be a third-party or cloud service.

Backup, CSV and XLSX files may contain personal or financial information and are not additionally encrypted by WorkTrack. After a file is transferred to a user-selected destination, WorkTrack does not control that service's storage, retention or deletion practices.

6. Selected files and background images

Android Photo Picker and file picker flows give WorkTrack access only to files selected by the user. WorkTrack does not request unrestricted access to the user's photo library or device storage.

When a background image is selected, WorkTrack stores a processed local copy for display. The image is not sent to Miia Forge. It may be included in a backup created by the user or by an enabled WorkTrack backup feature where supported.

7. Internet, official holidays and notifications

For official public holidays, WorkTrack uses the external Nager.Holidays HTTPS API at nagerholidays.com. Requests include the selected holiday country code, year and standard technical HTTPS request information.

The external server technically receives the device's public-facing IP address. Work records, rates, earnings, notes, custom holiday titles and background images are not included in these holiday requests.

The official holiday calendar is enabled by default. Requests may run automatically, including in the background for official holiday reminders. Results are cached locally. Users can disable the official holiday calendar in WorkTrack settings.

Notifications are local reminders scheduled using Android WorkManager, not Firebase Cloud Messaging. On supported Android versions, notification permission is requested.

8. Advertising, analytics and third-party services

WorkTrack 1.0 contains no advertising.

It does not use Firebase Analytics, Google Analytics, AdMob, Advertising ID, advertising SDKs, Crashlytics, Sentry or tracking SDKs. It does not use Firebase Cloud Messaging.

Google Drive backup, the external holiday API, Android system backup and user-selected sharing or storage services are functional integrations rather than advertising or analytics integrations.

9. Security, retention and control of data

WorkTrack uses Android internal application storage. Network connections to supported online services use HTTPS.

Exported files are not additionally encrypted by WorkTrack and absolute security cannot be guaranteed. Users should protect their device, Google account and exported backup files.

Records can be edited and deleted inside WorkTrack. All local application data can also be cleared through Android settings.

Copies stored in Google Drive application data, Android system backup or user-selected external storage must be managed separately through the relevant feature, service or account settings.

Where applicable data-protection laws provide such rights, users may have rights including access, correction, erasure, restriction, portability, objection and the right to lodge a complaint with a supervisory authority.

Because WorkTrack does not upload work records to a Miia Forge server, Miia Forge does not hold a separate server copy of those records to retrieve or delete.

10. Policy updates

This policy may be updated when WorkTrack functionality or data-processing practices change. The date at the top of this document identifies the current revision.

New processing and any required consent mechanisms will be described before such processing is introduced.
